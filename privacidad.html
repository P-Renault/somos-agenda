Política de Privacidad — Agenda Ya

Última actualización: 7 de octubre de 2026

Agenda Ya es una plataforma de gestión y reserva de servicios desarrollada por Somos Software. Esta política explica, de forma general, qué datos podemos tratar cuando una persona utiliza la plataforma, crea una cuenta, inicia sesión o realiza una reserva.

1. Datos que podemos recopilar

  • Nombre y apellidos.
  • Dirección de correo electrónico.
  • Información básica del perfil proporcionada por un proveedor de inicio de sesión social, cuando la persona autoriza ese acceso.
  • Datos necesarios para gestionar reservas, como teléfono u otra información de contacto que la persona entregue voluntariamente.
  • Información técnica necesaria para mantener la seguridad y funcionamiento del servicio.

2. Para qué utilizamos los datos

  • Crear y administrar cuentas.
  • Autenticar usuarios mediante correo electrónico o proveedores sociales habilitados.
  • Gestionar negocios, servicios, profesionales, disponibilidad y reservas.
  • Enviar comunicaciones relacionadas con la cuenta, reservas o funcionamiento del servicio.
  • Prevenir abusos, fraude y accesos no autorizados.
  • Mejorar la seguridad y funcionamiento de Agenda Ya.

3. Inicio de sesión con Facebook

Si utilizas Facebook para iniciar sesión, Agenda Ya puede recibir los datos que Facebook autorice y entregue para la autenticación, principalmente información básica de perfil y correo electrónico cuando esté disponible. El tratamiento se limita a los fines necesarios para crear y administrar la cuenta y prestar el servicio.

4. Servicios tecnológicos

Agenda Ya utiliza servicios tecnológicos de terceros para prestar funciones de autenticación, almacenamiento y operación de la plataforma. El acceso a datos se limita a lo necesario para prestar dichas funciones y se aplican controles de acceso apropiados.

5. Conservación y seguridad

Conservamos los datos durante el tiempo necesario para prestar el servicio, cumplir obligaciones legales y resolver cuestiones de seguridad. Aplicamos medidas técnicas y organizativas razonables para proteger la información.

6. Derechos y solicitudes

Puedes solicitar información, corrección o eliminación de tus datos personales escribiendo a reaultsantanapj@gmail.com. Las solicitudes podrán requerir información suficiente para verificar la identidad del solicitante.

7. Eliminación de datos

Para conocer el procedimiento específico para solicitar la eliminación de los datos asociados a tu cuenta, visita nuestra página de eliminación de datos.

8. Cambios a esta política

Esta política puede actualizarse para reflejar cambios en Agenda Ya, sus funciones o requisitos legales. La fecha de actualización indicada al comienzo de esta página identifica la versión vigente publicada.
