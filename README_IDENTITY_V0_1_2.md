# Agenda Ya · Identity v0.1.2 · Backup-1.0

Paquete de integración del motor Identity sobre el framework visual actual de Backup-1.0.

## Ajuste de esta revisión

- El login utiliza el ancho útil del dispositivo móvil (`94vw`) en lugar de una tarjeta estrecha.
- Se conserva una proporción visual amplia y legible en móviles.
- Se reducen principalmente espacios verticales en pantallas de poca altura, no el ancho ni los controles.
- El formulario completo permanece diseñado para una sola vista móvil habitual.
- El mensaje de respuesta de Supabase permanece dentro del flujo visible del formulario.
- Se conserva el logo oficial y la identidad gráfica de Backup-1.0.
